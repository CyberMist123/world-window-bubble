# 世界之窗泡泡 · AI 协作推流协议 (AI-COLLAB)

这个目录（`feed-profile/`）是「世界之窗 · 漫游画册」网页与本机所有 AI（Argon、Claude Code、Fable、GPT 等）共享的偏好与推流投递站。无需数据库，全用纯文本 JSON / Markdown / JSONL，方便人手随手改，也方便 AI 直接读写。

## 文件分工

1. **`preferences.md` & `preferences.json`（当前口味与频道权重）**
   - 网页右上角「调音台」里保存的内容会实时同步写进这两个文件。
   - `freeformNote`：主人随手写的自然语言口味备注（比如最近想多看宋瓷影青、印象派或某类冷门句子，不想看什么）。
   - `channels`：6 个窗口频道的标题、检索词（`query`）和权重（`weight`：`0`～`5`，越高分配到的气泡槽位和轮播越密，`0` 则让出主泡给高权重频道）。
   - `theme` / `fontPreset` / `seenMode` / `detailMode`：当前视觉主题、字体预设、已读去重策略与详情页默认模式（`scroll` 画卷 / `podcast` 播客）。

2. **`seen.json`（已曝光去重账本）**
   - 结构：`{ "updatedAt": "...", "items": { "<itemId>": 1794640000000 } }`
   - 网页根据 `seenMode`（`inspect` 点开/展开气泡即算看过，或 `open` 每次打开整屏曝光即记为已读）自动写入，下次打开或点「换一窗」时不再重复推送这些 ID。

3. **`signals.jsonl`（轻量口味信号流水，不做收藏夹/展柜）**
   - 每行一条 JSON：`{"ts":"...","action":"more"|"less","id":"...","title":"...","channel":"...","tags":[...],"source":"..."}`
   - 主人在画卷或播客页点「偏爱这类」或「少推这类」时追加写入。后续 AI 给她挑新东西前，先扫一眼最后 20 行就能摸准近期口味变化。

4. **`ai-inbox.json`（AI 投递箱）**
   - 任何本机 AI 想给她塞新鲜的 4K 画作、古物、风景或有意思的短句/神话切片，直接往 `ai-inbox.json` 数组里追加对象即可（未出现在 `seen.json` 里的条目会在下次打开或点「换一窗」时优先浮现）：
   ```json
   [
     {
       "id": "ai-20261114-borges-sand",
       "channel": "quotes",
       "kind": "quote",
       "title": "沙之书与无限页码",
       "subtitle": "豪尔赫·路易斯·博尔赫斯 · 《沙之书》",
       "quote": "线条是由无数个点构成的；平面是由无数条线构成的；书卷是由无数个平面构成的……没有哪一页是第一页，也没有哪一页是最后一页。",
       "story": "博尔赫斯晚年失明后常想：如果有一本书像沙子一样无始无终，翻过的一页永远无法再翻回第二次，人会为它着迷还是恐惧？最後叙述者把这本无限之书藏进了国立图书馆潮湿的地下书架——藏匿一片树叶最好的地方，就是森林。",
       "meta": ["文学切片", "无限与迷宫", "AI 投递"],
       "palette": ["#7ca9a2", "#eef6f4", "#d9b391"]
     }
   ]
   ```
   - 若投递 4K 图片类条目，`kind` 填 `"image"`，附上 `thumbUrl`（600–1000px 预览图）和 `fullUrl`（3000px+ 4K 高清原图）即可。
